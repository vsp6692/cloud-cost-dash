# Phase 03 — Monorepo, local dev, CI, standards: Requirements

Status: **NOT STARTED** · Release: v0.1 · Owner: TBD

Priority: **M** = must for phase exit, **S** = should, **C** = could. Traces refer to [PRD](../../product/PRD.md) IDs, ADRs and open questions. Acceptance IDs refer to [ACCEPTANCE.md](ACCEPTANCE.md); test IDs to [TEST_PLAN.md](TEST_PLAN.md).

## Functional and structural requirements

| ID | Requirement | Traces to | Pri | Verified by (AC) | Tests |
|---|---|---|---|---|---|
| P03-R01 | The repository follows the README layout (`apps/`, `internal/`, `providers/`, `sdk/`, `database/`, `schemas/`, `api/openapi/`, `deploy/`, `tests/`, `compliance/`, `scripts/`) as a single Go module plus a pnpm workspace. Empty directories carry a README stating their owning phase. | FR-OPS-001, NFR-MNT-001, ADR-0001 | M | P03-AC01 | TC19 |
| P03-R02 | One Go binary `cloudledger` exposes run modes `api`, `worker`, `scheduler`, `migrate`, `admin` and `version`. Unknown modes exit non-zero. `apps/api` and `apps/worker` are thin entrypoints delegating to the same command tree. Graceful shutdown on SIGTERM within a configurable drain timeout (default 30 s). | ADR-0001, FR-OPS-001 | M | P03-AC01, P03-AC02 | TC10, TC11, TC44 |
| P03-R03 | Configuration loads from defaults → YAML file (`--config` / `CLOUDLEDGER_CONFIG_FILE`) → `CLOUDLEDGER_*` env vars (highest precedence). Unknown keys fail in strict mode and warn otherwise. Invalid values fail startup with exit code 2. Secret-typed values are redacted in logs and in `cloudledger admin config dump`. Every key is documented in `docs/operations/CONFIGURATION.md`, generated from the config struct. | FR-OPS-001, NFR-SEC-003, COMPATIBILITY (config keys) | M | P03-AC05 | TC01–TC04, TC41 |
| P03-R04 | `GET /healthz` (liveness, no dependencies), `GET /readyz` (PostgreSQL reachable and schema at the binary's expected migration version; object store reachable in worker mode) and `GET /api/v1/version` are served as specified in [API_CONTRACTS.md](API_CONTRACTS.md). `readyz` returns 503 while draining or when a dependency fails. | FR-OPS-001, API_GUIDELINES §13 | M | P03-AC02 | TC05–TC09, TC11 |
| P03-R05 | OpenTelemetry bootstrap: structured JSON logs (slog) with `trace_id`/`span_id`; OTLP trace and metric export (disabled unless an endpoint is configured); Prometheus `/metrics` on a separate admin port. `tenant_id` is never a metric label. Request IDs are propagated and echoed. | FR-OPS-002, NFR-OBS-001, ADR-0017 | M | P03-AC04 | TC12, TC13 |
| P03-R06 | Docker Compose Lite skeleton (`make up` / `make down`) starts PostgreSQL, MinIO, api, worker (embedded scheduler) and web with health checks. Images are distroless or scratch-based, non-root, read-only root FS, with dropped capabilities. | FR-OPS-001, OQ-03, DEPLOYMENT_PROFILES | M | P03-AC03 | TC15, TC16, TC44 |
| P03-R07 | `apps/web` skeleton: Next.js App Router, TypeScript strict, Tailwind, shadcn/ui, ESLint, Vitest, Playwright with axe-core, an i18n string catalog, `GET /api/health`, and a placeholder typed API client generated from the OpenAPI document. | FR-OPS-001, ADR-0002, NFR-A11Y-001, NFR-I18N-001 | M | P03-AC03 | TC15, TC17, TC18 |
| P03-R08 | A `Makefile` provides the planned targets ([IMPLEMENTATION.md](IMPLEMENTATION.md#make-targets-planned)). A fresh clone on a clean runner completes `make bootstrap && make build && make test` within 20 minutes with no network calls other than toolchain and dependency downloads. `make test-cloud-{aws,gcp,azure}` are env-gated stubs that report SKIPPED, not PASS, when credentials are absent. | NFR-MNT-001, phase verification | M | P03-AC01 | TC19, TC43 |
| P03-R09 | Migration tool chosen and recorded in ADR-0018 (Proposed). `database/postgres/migrations/0001_bootstrap.sql` creates extensions (`citext`, `ltree`, `pgcrypto`) and roles `cloudledger_owner`, `cloudledger_migrator`, `cloudledger_app` (NOLOGIN parent / LOGIN child, **no `BYPASSRLS`, no superuser, not owner**) and `cloudledger_platform`. Migrations are forward-only, checksummed and linted for destructive changes. Sequence ranges are reserved per phase. | DATABASE_SCHEMA conventions, ADR-0003, NFR-SEC-001 (foundation) | M | P03-AC06 | TC06, TC08, TC21–TC23 |
| P03-R10 | Decimal library chosen and recorded in ADR-0019 (Proposed), wrapped in `internal/platform/money` (`Decimal`, `Money{Amount, Currency}`), with JSON string serialization and half-even rounding helpers. A lint rule fails the build on `float32`/`float64` in money-bearing packages. | NFR-ACC-003, ADR-0007 | M | P03-AC06, P03-AC07 | TC24, TC25 |
| P03-R11 | Import-lint enforces module boundaries: `internal/platform` imports no other internal module; domain modules import only other modules' exported `api` packages; `providers/*` and `sdk/*` never import `internal/*`; permissive-path packages (per LICENSE_MAP / OQ-22) never import core packages; no import cycles. | ADR-0001, SYSTEM_CONTEXT §module rules, LICENSE_MAP rule 3 | M | P03-AC07 | TC26, TC27 |
| P03-R20 | `internal/platform` provides `timeutil` (UTC-only clock, injectable for tests), `ids` (UUIDv7) and the `jobs.Queue`/`jobs.Handler` interfaces with an in-memory test implementation only (real PG queue in Phase 04). | ADR-0016, ADR-0005, OQ-05 | S | P03-AC16 | TC42 |

## CI, quality and security requirements

| ID | Requirement | Traces to | Pri | Verified by (AC) | Tests |
|---|---|---|---|---|---|
| P03-R12 | CI on every PR and `main`: format check, `golangci-lint`, ESLint/tsc, unit tests with coverage (reported; ≥ 85 % gate wired for packages listed in `.coverage-core.txt`, empty in this phase), integration tests with Testcontainers PostgreSQL, multi-arch (linux/amd64, linux/arm64) image build. Required checks are enforced by branch protection. | NFR-MNT-001, NFR-PORT-001 | M | P03-AC08 | TC20, TC28 |
| P03-R13 | Security scanning: CodeQL (Go, JS/TS), Semgrep (default + custom rules), Trivy (vulnerability, misconfiguration, license), Gitleaks on PR diff and full history. Critical/high findings fail the build unless an expiring, approved waiver exists. | NFR-SEC-005, NFR-SEC-003, NFR-SEC-002 (foundation) | M | P03-AC09 | TC16, TC29–TC31 |
| P03-R14 | Supply chain: GitHub Actions pinned to commit SHAs, dependency lockfiles committed, Syft SBOM (SPDX and CycloneDX, with license data) per image build, Cosign keyless signature and SBOM attestation on `main` builds, Renovate/Dependabot for pinned updates. Workflows use least-privilege `permissions:`. | NFR-SEC-005 | M | P03-AC10 | TC32 |
| P03-R19 | Engineering standards: `docs/contributors/DEVELOPMENT.md` (setup, targets), `CODING_STANDARDS.md` (Go, TS, SQL, errors, logging, no secrets/tenant data in code), Conventional Commits, PR template with security/licensing checklist, CHANGELOG *Unreleased* discipline, `make docs-lint` (links, phase ID uniqueness). | NFR-MNT-001, phase execution rules | S | P03-AC15 | TC41 |

## [LIC] License compliance requirements

| ID | Requirement | Traces to | Pri | Verified by (AC) | Tests |
|---|---|---|---|---|---|
| P03-R15 | Dependency license checks per [LICENSE_COMPLIANCE.md §2–3](../../legal/LICENSE_COMPLIANCE.md): go-licenses against `compliance/allowed-licenses.txt`; `scripts/compliance/check-npm-licenses.mjs` over `pnpm licenses list --json`; Trivy license scan of images. | P03-R16 | Every source file carries the SPDX header specified in [LICENSE_MAP.md](../../legal/LICENSE_MAP.md) (core: `LicenseRef-CloudLedger-SAL-1.0`; interface paths per the OQ-22 decision from Phase 02). `REUSE.toml` and `LICENSES/` make the tree REUSE-compliant; `reuse lint` fails on missing or wrong identifiers. | NFR-LIC-002 | M | P03-AC12 | TC37 |
| P03-R17 | CLA Assistant (`cla/required`) and DCO checks are required on PRs. `.github/CODEOWNERS` assigns Licensor-designated approvers to `LICENSE*`, `CLA.md`, `COMMERCIAL_LICENSE.md`, `TRADEMARK_POLICY.md`, `LICENSE_FAQ.md`, `docs/legal/**`, `compliance/**`, `REUSE.toml`, `LICENSES/**`. External contributions stay disabled until OQ-23 is counsel-approved. | NFR-LIC-003, OQ-23 | M | P03-AC13 | TC38, TC39 |
| P03-R18 | An automated check proves the product contains no license-key validation, feature gating by license, seat/account/resource usage limits or phone-home license enforcement; telemetry is off by default with no outbound calls at startup. Implemented as Semgrep rules plus a Go test over the source tree with a seeded-violation fixture. | NFR-LIC-004, OQ-17, PRD A4 | M | P03-AC14 | TC14, TC40 |
