# Phase 09: Test Plan

Fixtures live under `tests/fixtures/imports/` and follow the plan in [GENERIC_IMPORTS.md §9](../../providers/GENERIC_IMPORTS.md#9-fixture-plan-phase-09). Every expected data-quality report and every expected total is a **golden JSON file** compared with exact decimal string equality. Attack files are generated by a script (`tests/fixtures/imports/attack/gen.go`) and not committed when they are large.

## Environments
| Env | Purpose |
|---|---|
| Local / CI (Testcontainers) | PostgreSQL 16, MinIO, fake-gcs-server, Azurite. Network egress monitor container for TC16 |

No real cloud credentials are needed. Results from real-cloud polling, if run, must be labelled separately.
