- `tests/fixtures/analytics/golden/`: shared golden dataset (multi-provider FOCUS rows from Phase 11 golden outputs, 3 tenants, 2 currencies, 14 months, tags with case variants, missing tags, NULL resource IDs, credits, tax, corrections, values at x.xxxxxxxxxxxx5 boundaries, max-magnitude values near Decimal(38,12) limits). Expected results stored as canonical JSON with decimal strings; generated by an independent Go reference evaluator using `apd`, not by any engine.
- `tests/fixtures/analytics/queries/`: 200+ semantic queries (YAML) with expected outputs.
- `tests/fixtures/analytics/injection/`: tag keys/values with `'; DROP TABLE`, `{{7*7}}`, `</script>`, NUL, emoji, RTL.
