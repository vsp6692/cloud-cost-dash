# Phase 35 Requirements

Priority: **M** = must (phase exit blocker), **S** = should, **C** = could. Every requirement is verified by the listed acceptance criterion in [ACCEPTANCE.md](ACCEPTANCE.md).

| ID | Requirement | PRD trace | Pri | Verified by |
|---|---|---|---|---|
| P35-R01 | `sdk/provider` is published as Go module major version v1 with the interfaces, types and classified error types in [PROVIDER_SDK.md](../../contracts/PROVIDER_SDK.md) §2. After v1.0.0, CI rejects any backward-incompatible change to exported identifiers (API diff). | FR-SDK-001, NFR-CMP-001 | M | P35-AC01 |
| P35-R02 | A versioned gRPC protocol (`cloudledger.provider.v1`) mirrors every SDK interface. Large iterators (`ListResources`, `OpenArtifact`, `QueryMetrics`, `ListPrices`) are server-streaming. In-process and gRPC providers satisfy the same Go `Provider` interface through an adapter. | FR-SDK-003 | M | P35-AC02 |
| P35-R03 | The plugin host performs a handshake (magic cookie, protocol version negotiation with explicit min/max, per-launch mTLS on a Unix domain socket). Version mismatch or missing cookie aborts launch with a typed error and an audit event. | FR-SDK-003, NFR-SEC-001 | M | P35-AC03 |
| P35-R04 | The host checks the manifest `compatibility.sdk` and `compatibility.cloudledger` SemVer ranges before launch and refuses incompatible plugins with a clear admin-visible reason. | FR-SDK-003, NFR-CMP-001 | M | P35-AC03 |
| P35-R05 | Out-of-process plugins run sandboxed: dedicated non-root UID (or container), read-only root FS, CPU/memory/pids/fd limits, seccomp `RuntimeDefault`, no capabilities, egress restricted to the manifest's `execution.egress` allow-list (enforced where the platform allows: NetworkPolicy in Kubernetes, nftables/egress proxy in Compose), and no network route to PostgreSQL, the analytics store, object storage, KMS or the CloudLedger API. | FR-SDK-003, NFR-SEC-001, NFR-SEC-003 | M | P35-AC04 |
| P35-R06 | Plugins never receive raw long-lived secrets. A credential broker in the host issues per-call, connector-scoped, short-lived credentials (STS/WIF tokens or resolved secret references) over the gRPC `CredentialProvider` service. | FR-CON-003, NFR-SEC-003 | M | P35-AC04 |
| P35-R07 | Plugin crashes, hangs and resource exhaustion are contained: the host enforces per-call deadlines, restarts with exponential backoff (max 5 per 10 min), then marks the plugin `degraded` and surfaces this in connector health without affecting other connectors or tenants. | FR-CON-005, FR-ING-004, NFR-AVL-001 | M | P35-AC05 |
| P35-R08 | `schemas/manifest/plugin-manifest.v1.json` (JSON Schema 2020-12) is the single source for manifest validation. It is strict (`additionalProperties: false`), and manifests are immutable per plugin version (checksum stored). | FR-CON-001, FR-SDK-001 | M | P35-AC06 |
| P35-R09 | **[LIC]** `metadata.license` is **required** and must be a syntactically valid SPDX license expression (SPDX License List identifiers, `LicenseRef-*`, `WITH`, `AND`, `OR`). Invalid or missing values fail validation in `cloudledger-sdk validate`, the testkit and installation. | NFR-LIC-002, FR-CON-001 | M | P35-AC07 |
| P35-R10 | **[LIC]** The declared license is **informational only**: no code path accepts, rejects, limits, meters or disables a plugin or any core feature based on its license value, and nothing phones home. | NFR-LIC-004 | M | P35-AC07 |
| P35-R11 | **[LIC]** The admin Plugins page and `GET /api/v1/admin/plugins` show each installed plugin's declared license, and the manifest validation log records it. | NFR-LIC-002 | M | P35-AC08 |
| P35-R12 | `cloudledger-sdk` CLI provides `init` (scaffold), `validate` (manifest + layout), `test` (compatibility suite), `package` (reproducible tarball + checksum + SBOM) and `run --dev` (local host). | FR-SDK-001, UJ-12 | M | P35-AC09 |
| P35-R13 | `sdk/provider/testkit` implements every test group in PROVIDER_SDK.md §4 and runs identically against in-process and gRPC plugins. A manifest that declares an unimplemented capability (or omits an implemented one) fails the suite. | FR-SDK-001, UJ-12, AC-08 | M | P35-AC10 |
| P35-R14 | `providers/examples/examplecloud` compiles with only `sdk/provider` (and allow-listed third-party) imports and passes the suite in both execution modes with **no change to core** (`internal/`, `apps/`). AWS, GCP and Azure providers also pass the frozen suite. | AC-08, FR-SDK-001 | M | P35-AC10 |
| P35-R15 | Admin plugin management API: list, install (from a local path or uploaded package with checksum), enable, disable. Install and state changes are audited. Platform-admin only. | FR-SDK-003, FR-AUD-001 | M | P35-AC08 |
| P35-R16 | **[LIC]** The OQ-22 decision is applied: `sdk/provider` (interfaces, types, proto, manifest schema), `sdk/provider/testkit` and `schemas/manifest` carry SPDX headers matching [LICENSE_MAP.md](../../legal/LICENSE_MAP.md) (Option A `Apache-2.0` or Option B `LicenseRef-CloudLedger-SAL-1.0 WITH LicenseRef-CloudLedger-Plugin-Exception`), and the testkit is licensed the same as the interfaces. | NFR-LIC-002, AC-11 | M | P35-AC11 |
| P35-R17 | **[LIC]** Import-lint: no package under a permissive (Plugin Interface) path imports `internal/**`, `apps/**`, first-party `providers/{aws,gcp,azure}` or any other core path. CI fails on violation. | NFR-LIC-002 | M | P35-AC11 |
| P35-R18 | **[LIC]** In-tree plugins under `providers/**` (other than the designated example path) require a signed CLA and `LicenseRef-CloudLedger-SAL-1.0` headers; `cla/required`, `reuse lint` and DCO checks gate merges. | NFR-LIC-002, NFR-LIC-003 | M | P35-AC12 |
| P35-R19 | **[LIC]** Out-of-tree plugin rules (build only against Plugin Interfaces, do not bundle CloudLedger, declare `license` + `LICENSE` file, trademark-compliant naming, no copied core source) are documented in the plugin authoring guide and emitted in the scaffold's README and NOTICE template. | NFR-LIC-002, FR-SDK-004 | M | P35-AC12 |
| P35-R20 | Plugin processes emit OTel traces and metrics through the host (trace context propagated over gRPC metadata); plugin logs are captured, size-limited and redacted. | FR-OPS-002, NFR-OBS-001 | S | P35-AC05 |
| P35-R21 | `cloudledger-sdk package` produces a reproducible artifact with SPDX SBOM including license data, so catalog requirements in PLUGIN_LICENSING §4 can be met in Phase 37. | NFR-SEC-005, NFR-LIC-002 | S | P35-AC09 |

## Traceability notes

- AC-08 (Extensibility) is partially satisfied here (provider half); the recommendation-plugin half is Phase 36.
- AC-11 (License compliance) is contributed to (headers, import-lint, manifest license) and gated finally in Phase 38.
- OQ-14 (plugin execution model) must be **Accepted** before P35-T03; OQ-22 must be **decided** before exit.
