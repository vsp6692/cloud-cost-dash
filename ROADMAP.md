# Roadmap

> CloudLedger is in **pre-alpha planning**. No application code has been written. Releases are scope checkpoints, not dates.

| Release | Phases | Highlights | Status |
|---|---|---|---|
| v0.1 | 01–05 | PRD and licensing decision, architecture and ADRs, monorepo and CI (incl. license compliance), tenancy and audit, SSO/RBAC/ABAC | Planning (Phase 01 next) |
| v0.2 | 06–14 | AWS, GCP and Azure billing ingestion, file imports, invoices, FOCUS normalization, backfill and health, PG/DuckDB/ClickHouse analytics, dashboards | Not started |
| v0.3 | 15–18 | Tag allocation and shared costs, dashboard builder, budgets, forecasts, anomalies, FX, commitments, unit economics | Not started |
| v0.5 | 19–26 | Inventory, telemetry, recommendation SDK and rules (compute, K8s, storage, DB, network, commitments), lifecycle and realized savings | Not started |
| v0.7 | 27–30 | Governed AI assistant, finance exports, reconciliation, period close, scheduled reports | Not started |
| v0.9 | 31–37 | SAML/SCIM, MSP mode, integrations, HA/DR, scale and pen testing, plugin SDKs, contributor governance | Not started |
| v1.0 | 38–40 | Release certification, public docs, stable release and support policy | Not started |
