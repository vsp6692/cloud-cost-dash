# Changelog

All notable changes to this project will be documented in this file. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project will use [Semantic Versioning](https://semver.org/) from its first release.

## [Unreleased]

### Added
- Planning and architecture documentation: PRD, architecture (C4, data flows, deployment profiles, tenancy, schemas, ingestion, FOCUS normalization, allocation, finance, inventory, recommendations, forecasting, LLM security), ADRs, contracts (API guidelines, OpenAPI draft, provider SDK, capability manifest, events, compatibility), security architecture, provider integration guides, planning artifacts (dependency graph, risk register, backlog, release plan, acceptance and traceability matrices), and specifications for all 40 phases.
- Source-available licensing framework (**drafts pending legal review**): `LICENSE.md` (proposed CL-SAL-1.0), `COMMERCIAL_LICENSE.md`, `LICENSE_FAQ.md`, `CLA.md`, `TRADEMARK_POLICY.md`, and `docs/legal/` (licensing evaluation, license map, plugin licensing rules, license compliance CI policy).

### Changed
- Licensing model changed from the originally proposed Apache-2.0 to a source-available model: free for internal use (including production), with a commercial license required for redistribution, resale, white-labeling, embedding and third-party hosting. No application code existed at the time of the change.

_No application code has been released._
